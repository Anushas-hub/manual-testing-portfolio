# API Testing - Postman Project

## Overview
This project contains manual API testing work on the ReqRes public REST
API, performed using Postman as part of my Manual Testing Portfolio.

## What's Inside
- `collection.json` - Postman collection with 11 requests across Users,
  Auth, and Negative Scenarios folders, each validated with automated
  assertions (pm.test).
- `environment.json` - Postman environment with the base URL variable
  used across all requests.
- `API_Testing_Test_Case_Report.xlsx` - full test case report with
  expected vs actual results, pass/fail status, and an execution summary.

## What This Project Demonstrates
- API testing fundamentals: GET, POST, PUT, DELETE
- Status code validation (200, 201, 204, 400, 404)
- Positive and negative test design
- Postman environment variables for scalable, maintainable requests
- Automated test assertions instead of manual response checking
- Structured, professional test documentation

## How to Run This Collection
1. Import `collection.json` into Postman
2. Import `environment.json` and select it as the active environment
3. Click "Run" on the collection to execute all 11 requests
