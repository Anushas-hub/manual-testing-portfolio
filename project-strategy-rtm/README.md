# Forgot Password: Test Strategy & RTM

A mock QA project showing the full chain from requirement to test coverage for a "Forgot Password" feature.

# What's inside

| File | Description |
|------|-------------|
| `Project_Test_Strategy_RTM.pdf` | Test strategy document: user story, acceptance criteria, test scenarios, test flow diagram, 18 test cases and the RTM |
| `Project_Test_Cases_RTM.xlsx` | Editable spreadsheet of the test cases and RTM, for execution and tracking |

# Scope
- 6 requirements (R1 to R6) taken from the acceptance criteria
- 18 test cases: positive, negative and boundary
- Requirement Traceability Matrix mapping every requirement to its test cases

## Skills demonstrated
Requirement analysis, test scenario design, boundary value analysis, negative testing, traceability.
